## 1. Objectives

In this lab, a **non-blocking** embedded sound monitoring system was developed, the main feature of which is continuous sound measurement using a **microphone module** with approximation of ADC values into relative dB values. The representative data is displayed through **LCD 16x2** module, giving constant feedback to the user. The system mainly reacts to elevated noise through two threshold mechanisms: the microphone module’s digital threshold output for interrupt-based event detection and a software-defined relative dB threshold for state evaluation, while giving feedback by lighting an external LED.

As an extension to the original system the Python-based GUI was implemented through serial UART communication, helping to visualize how the real time surrounding sound changes through animated widgets. New sound events whose estimated level exceeds the software-defined threshold are recorded and stored into the CSV log file.

### 2.2 Microphone

![image](images/Pasted%20image%2020260320091601.png)

The microphone module is based on an **electret microphone**, which converts sound waves into a small electrical signal. The module provides two useful outputs: **analog output (AO)** and **digital output (DO)**, where the analog output changes continuously with sound intensity, so it can be read by the Arduino ADC for monitoring the sound level, but the digital output is generated by an on-board **LM393 comparator**, which compares the microphone signal with a threshold set by the small potentiometer on the module. When the sound exceeds that threshold, the digital output changes its state, so the module can also be used as a simple sound-event detector [2].

The sensitivity of the microphone can be tuned using microphones potentiometer. Using the orientation as in the above image, by turning the knob to the right, the sensitivity will increase, left - decrease.  

Such microphone modules are mainly suitable for **relative sound detection**, not for precise calibrated sound-pressure measurement in absolute dB. Therefore, in this lab the module is appropriate for detecting whether the environment is quieter or louder and whether the selected threshold has been crossed [2]. 

In the implemented system, the analog output is read through A0, while the digital output is connected to pin D2 and used for interrupt-based event detection.

### 2.3 ADC and Sound Level Estimation

As was mentioned before, the microphone sensor lacks the ability of measuring dB levels, therefore in this lab dBs were estimated using ADC signals. By repeatedly reading analog signals from microphone using `analogRead()` and converting those signals into 10-bit ADC values, program collects samples over 50 ms window, after which computes an RMS-resembling (Root Mean Square) value using the following relation
$$RMS = \sqrt {E[x^2]-(E[x])^2}$$
here $E[x]$ is the mean of samples and $E[x^2]$ is the mean square. Using RMS value, which is then converted into voltage and after into a relative dB level by logarithmic formula, approximate value is achieved. Once again, this is **not absolute dB SPL**, but a **relative sound level** referenced to a selected voltage. But in the scope of this lab, it is enough to make  threshold-based decisions.

### 2.4 Interrupts and Non-Blocing Operation

In this lab, two methods for non-blocking operation were used: **millis()-based timing** and **interrupts**.

Crucial idea of this lab is the implementation of **non-blocking** operation. Blocking code is undesirable since it pauses execution of the program and prevents CPU from doing other work - this can end up with the program missing an important event or condition. Non-blocking code keeps the loop constantly running and continuously checks time to find out whether enough time passed to start the execution of each task.

Using the idea of **millis-based timing** instead of long delays, program separates time intervals for various actions:
- **50ms** - sound calculation
- **200ms** - LCD refresh
- **100ms** - UART (serial) transmission
- **300ms** - LED feedback

Along with that, **interrupt** handles sound events immediately. 

### 2.5 UART and GUI logging

In Arduino program the data is sent using UART communication at **9600 baud rate**. The message sent contains _current time_ (Arduino `millis()`), _sound level_, _software threshold state_, and _event count_ (how many hardware interrupts occurred).

In PC, the PyQt6 app catches and reads the serial data sent from Arduino periodically using `QTimer`, updates GUI, stores new threshold events into CSV file.

## 4. Implementation (Code Walkthrough)

### 4.1 `main.cpp` - Arduino's Firmware

```cpp title:"main.cpp"
#include <Arduino.h>
#include <LiquidCrystal.h>
#include <math.h>

LiquidCrystal lcd(12, 11, 5, 4, 3, 6);

const byte LED_PIN = 8;
const byte MIC_AO  = A0;
const byte MIC_DO  = 2;

const float ADC_REF_VOLTAGE = 5.0;
const float DB_REFERENCE_V  = 0.02;
float DB_THRESHOLD = 15.0;

const unsigned long WINDOW_MS = 50;
const unsigned long LCD_MS    = 200;
const unsigned long SERIAL_MS = 100;
const unsigned long LED_ON_MS = 300;

unsigned long sampleCount = 0;
double sumSamples = 0.0;
double sumSquares = 0.0;

float vrms = 0.0;
float dbLevel = 0.0;
bool aboveThreshold = false;

volatile bool soundInterruptFlag = false;
volatile unsigned long interruptCount = 0;

unsigned long lastWindowStart = 0;
unsigned long lastLcdUpdate   = 0;
unsigned long lastSerialSend  = 0;
unsigned long ledStartTime    = 0;

bool ledOn = false;

void soundISR() {
  soundInterruptFlag = true;
  interruptCount++;
}

void setup() {
  pinMode(LED_PIN, OUTPUT);
  pinMode(MIC_DO, INPUT);

  digitalWrite(LED_PIN, LOW);

  lcd.begin(16, 2);
  lcd.setCursor(0, 0);
  lcd.print("Sound dB Meter");
  lcd.setCursor(0, 1);
  lcd.print("Starting...");

  Serial.begin(9600);

  attachInterrupt(digitalPinToInterrupt(MIC_DO), soundISR, FALLING);

  lastWindowStart = millis();
  lastLcdUpdate   = millis();
  lastSerialSend  = millis();
}

void loop() {
  unsigned long now = millis();

  int sample = analogRead(MIC_AO);

  sampleCount++;
  sumSamples += sample;
  sumSquares += (double)sample * (double)sample;

  if (now - lastWindowStart >= WINDOW_MS) {
    if (sampleCount > 0) {
      double mean = sumSamples / sampleCount;
      double meanSquare = sumSquares / sampleCount;

      double variancePart = meanSquare - (mean * mean);
      if (variancePart < 0) variancePart = 0;
      double rmsCounts = sqrt(variancePart);

      vrms = (float)(rmsCounts * ADC_REF_VOLTAGE / 1023.0);

      if (vrms < 0.001) {
        vrms = 0.001;
      }

      dbLevel = 20.0 * log10(vrms / DB_REFERENCE_V);

      aboveThreshold = (dbLevel >= DB_THRESHOLD);
    }

    sampleCount = 0;
    sumSamples = 0.0;
    sumSquares = 0.0;
    lastWindowStart = now;
  }

  if (soundInterruptFlag) {
    noInterrupts();
    soundInterruptFlag = false;
    interrupts();

    ledOn = true;
    ledStartTime = now;
    digitalWrite(LED_PIN, HIGH);
  }

  if (ledOn && (now - ledStartTime >= LED_ON_MS)) {
    ledOn = false;
    digitalWrite(LED_PIN, LOW);
  }

  if (now - lastLcdUpdate >= LCD_MS) {
    lastLcdUpdate = now;

    lcd.setCursor(0, 0);
    lcd.print("dB:");
    lcd.print(dbLevel, 1);
    lcd.print("    ");

    lcd.setCursor(10, 0);
    lcd.print("T:");
    lcd.print(DB_THRESHOLD, 0);
    lcd.print(" ");

    lcd.setCursor(0, 1);
    lcd.print("Evt:");
    lcd.print(interruptCount);
    lcd.print("   ");

    lcd.setCursor(10, 1);
    if (aboveThreshold) {
      lcd.print("LOUD ");
    } else {
      lcd.print("quiet");
    }
  }

  if (now - lastSerialSend >= SERIAL_MS) {
    lastSerialSend = now;

    Serial.print(now);
    Serial.print(",");
    Serial.print(dbLevel, 1);
    Serial.print(",");
    Serial.print(aboveThreshold ? 1 : 0);
    Serial.print(",");
    Serial.println(interruptCount);
  }
}
```

#### 4.1.4 Sound Sampling, dB Estimation

- Inside the loop, the microphone's analog output is being read constantly using `analogRead(MIC_AO);`
- Each reading is collected during **50ms** sampling window. Then, the program calculates the mean
$$mean = \frac{\sum x}{N}$$ 
and mean square
$$meanSquare = \frac{\sum x^2}{N}$$
and using this formula
$$V_{RMS{}} = \sqrt {E[x^2]-(E[x])^2}$$
estimates the **AC RMS** part of the signal. After that, RMS value is converted into the voltage and then into **relative dB value** using
$$dB = 20log_{10}(\frac{V_{RMS}}{V_{REF}})$$
```cpp
if (variancePart < 0) variancePart = 0;
if (vrms < 0.001) vrms = 0.001;
```
- is important to avoid $log(0)$ 

- After all that, the program makes decision based on the preset threshold value.

As mentioned before, this is only estimated dB value and to make it more or less accurate the following can be done:
1. Use reliable measurement tool to measure the actual dB level in quiet room.
2. Tune `const float DB_REFERENCE_V  = 0.02;` until the measuring are similar on both devices.

#### 4.1.5  Interrupt handle and LED timing

When a hardware interrupt happens, the main loop catches it using `soundInterruptFlag`, then clears this flag and turns the LED on for **300 ms**.

#### 4.1.6 LCD Update

LCD is updated every **200ms**. First row on LCD displays current level sound with the threshold. Second row - event (interrupt) count and state (LOUD/quiet)

`lcd.print(dbLevel, 1);` prints the value with one decimal place, showing a bit more accurate measures

#### 4.1.7 UART Transmission

Data is sent to the serial every **100ms**. Packet contains following:
- Arduino current millis()
- current dB value
- threshold state
- event count
all separated by a coma, for convenient parsing in app.py

### 4.2 `app.py` Python Visualization Program

```python title:"app.py"
import sys
import csv
from datetime import datetime

import serial
import serial.tools.list_ports

from PyQt6.QtCore import QTimer

from PyQt6.QtWidgets import (
    QApplication,
    QWidget,
    QVBoxLayout,
    QLabel,
    QProgressBar,
    QListWidget
)

BAUD_RATE = 9600
CSV_FILE = "sound_events_db.csv"


def find_serial_port():
    ports = list(serial.tools.list_ports.comports())

    for p in ports:
        desc = (p.description or "").lower()
        if "arduino" in desc or "ch340" in desc or "usb serial" in desc:
            return p.device

    if ports:
        return ports[0].device

    return None


class SoundGUI(QWidget):
    def __init__(self):
        super().__init__()

        self.setWindowTitle("Sound dB Monitor GUI")
        self.resize(800, 400)

        self.serial_port = None
        self.prev_above = False

        self.status_label = QLabel("Status: starting...")
        self.db_label = QLabel("Current Sound Level: 0.0 dB")
        self.event_label = QLabel("Interrupt Event Count: 0")
        self.threshold_label = QLabel("Threshold State: below")

        self.bar = QProgressBar()
        self.bar.setRange(0, 60)
        self.bar.setValue(0)
        self.bar.setFormat("dB: %v")

        self.log_list = QListWidget()

        layout = QVBoxLayout()
        layout.addWidget(self.status_label)
        layout.addWidget(self.db_label)
        layout.addWidget(self.event_label)
        layout.addWidget(self.threshold_label)
        layout.addWidget(self.bar)
        layout.addWidget(QLabel("Logged Threshold Events (dB)"))
        layout.addWidget(self.log_list)
        self.setLayout(layout)

        self.csv_file = open(CSV_FILE, "w", newline="", encoding="utf-8")
        self.csv_writer = csv.writer(self.csv_file)

        if self.csv_file.tell() == 0:
            self.csv_writer.writerow(["pc_time", "arduino_ms", "db_level"])

        port = find_serial_port()
        if port is None:
            self.status_label.setText("Status: No serial port found")
        else:
            try:
                self.serial_port = serial.Serial(port, BAUD_RATE, timeout=0.05)
                self.status_label.setText(f"Status: Connected to {port}")
            except Exception as e:
                self.status_label.setText(f"Status: Error opening port: {e}")

        self.timer = QTimer()
        self.timer.timeout.connect(self.read_serial)
        self.timer.start(50)

    def read_serial(self):
        if not self.serial_port:
            return

        while self.serial_port.in_waiting:
            try:
                raw = self.serial_port.readline().decode(errors="ignore").strip()
                if not raw:
                    continue

                parts = raw.split(",")
                if len(parts) != 4:
                    continue

                arduino_ms = int(parts[0])
                db_level = float(parts[1])
                above = int(parts[2])
                event_count = int(parts[3])

                self.db_label.setText(f"Current Sound Level: {db_level:.1f} dB")
                self.event_label.setText(f"Interrupt Event Count: {event_count}")

                if above == 1:
                    self.threshold_label.setText("Threshold State: ABOVE")
                    self.bar.setStyleSheet("QProgressBar::chunk { background-color: red; }")
                else:
                    self.threshold_label.setText("Threshold State: below")
                    self.bar.setStyleSheet("QProgressBar::chunk { background-color: green; }")

                bar_value = max(0, int(db_level))
                self.bar.setMaximum(max(60, bar_value + 5))
                self.bar.setValue(bar_value)

                if above == 1 and not self.prev_above:
                    pc_time = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
                    self.csv_writer.writerow([pc_time, arduino_ms, f"{db_level:.1f}"])
                    self.csv_file.flush()

                    self.log_list.insertItem(0, f"{pc_time} | {db_level:.1f} dB")

                    if self.log_list.count() > 15:
                        self.log_list.takeItem(15)

                self.prev_above = (above == 1)

            except Exception:
                pass

    def closeEvent(self, event):
        try:
            if self.serial_port:
                self.serial_port.close()
        except Exception:
            pass

        try:
            self.csv_file.close()
        except Exception:
            pass

        event.accept()


def main():
    app = QApplication(sys.argv)
    window = SoundGUI()
    window.show()
    sys.exit(app.exec())


if __name__ == "__main__":
    main()
```
